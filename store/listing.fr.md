- Description :

Deux clubs. Une année. Qui est-ce ?

Mercato transforme trois décennies de vrais transferts de football en jeu de devinettes.
Chaque question présente un vrai transfert : le club quitté, le club rejoint et l'année.
Vous nommez le footballeur.

MODE FACILE
Quatre options par question, issues des transferts phares dont tout le monde parle.
Des manches rapides de dix questions.

MODE HARDCORE
Pas d'options. Tapez le nom, avec trois vies par question et des indices gratuits si besoin :
nationalité, poste, puis la forme du nom. Le moteur de correspondance tolère les fautes de
frappe et les accents, reconnaît les surnoms et refuse un simple nom de famille quand deux
joueurs le partagent.

DONNÉES RÉELLES, RIEN D'INVENTÉ
1 900+ vrais transferts, 500+ joueurs, 400+ clubs, de 1985 à aujourd'hui.
Que des faits : aucun transfert inventé.

JOUEZ PARTOUT
Le jeu complet est inclus dans l'application : aucun compte, aucune inscription,
entièrement jouable hors ligne. En anglais, en français et en espagnol.

MONÉTISATION ÉQUITABLE
Gratuit avec publicités. Un seul achat les supprime pour toujours. Pas de monnaie virtuelle,
pas d'énergie, pas d'abonnement.

## Notes pour le modérateur (les deux stores)

- Aucun compte, gameplay entièrement hors ligne ; le seul usage réseau est la publicité.
- Consentement : formulaire Google UMP dans l'EEE/RU, invite ATT sur iOS, choix de
  personnalisation intégré à l'application partout ailleurs.
- Achat unique non consommable `com.flegm.mercato.removeads` sur iOS, `mercato_remove_ads` sur Play (Supprimer les publicités), avec
  restauration.
- Pas de classement, pas de multijoueur dans cette version (ne pas mentionner dans
  les supports marketing).
